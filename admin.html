Sunucuda ADMIN_PASSWORD tanımlı değil; ekleme, silme ve ayarlar kapalı.

Kolay yol (token gerekmez): kelimeler depodaki kelimeler.txt, ayarlar ayarlar.txt dosyasında durur. Aşağıdaki düğme dosyayı GitHub'ın düzenleyicisinde açar; yeni kelimeleri her satıra bir tane yazıp Commit changes deyin. Oyun 1–2 dakika içinde güncellenir.

✎ kelimeler.txt dosyasını GitHub'da düzenle ⚙ ayarlar.txt dosyasını düzenle
Gelişmiş: bu panelden doğrudan eklemek (GitHub token'ı ister)

Depoya yazabilen bir erişim token'ı girerseniz ekleme, silme ve ayar değişiklikleri buradan commit olarak atılır. Token yalnızca bu sekme açıkken tarayıcıda tutulur.

  1. GitHub'da sağ üstten Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: "Only select repositories" seçip bu depoyu işaretle.
  3. Permissions → Repository permissions → Contents: "Read and write". Başka izin gerekmez.
  4. Oluşan github_pat_… değerini yukarıya yapıştır.

Not: Her değişiklik depoya bir commit olarak yazılır; GitHub Pages'teki oyun 1–2 dakika içinde güncellenir. Tarayıcı eski sürümü gösterirse sayfayı yenileyin.

Oyun ayarları

Buradaki ayarlar herkes için geçerlidir (sunucuda ya da depodaki ayarlar.txt dosyasında saklanır). GitHub modunda kolay yol: ayarlar.txt dosyasını GitHub'da düzenleyip "bonus harf" satırını evet ya da hayır yapın.

Kelime ekle

Kelimeleri boşluk, virgül veya satır sonuyla ayırarak yaz. 4–7 harfli, yalnızca Türk alfabesi; büyük/küçük harf fark etmez, tekrarlar atlanır. GitHub modunda kolay yol: kelimeler.txt dosyasını GitHub'da düzenleyin.
